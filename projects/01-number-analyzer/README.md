# Project 1 - Number Analyzer

A small command-line Python project built while learning Python.

## What it does

The program takes a number from the user and analyzes it.

It determines:

- Whether the number is positive, negative, or zero
- Whether the number is even or odd
- Whether the number is divisible by 5
- Its absolute value
- Its square
- Its cube

The improved version also:

- Uses functions
- Repeatedly accepts input
- Allows the user to quit with `q`
- Handles invalid integer input with `try` / `except`

## Versions

### `concept_learning.py`

The original version of the project.

This version was created while learning:

- Variables
- User input
- Conditions
- Arithmetic
- Modulo
- Basic Python functions

The only purpose of "concept_learning.py" was to learn the concept for making number_analyzer

### `number_analyzer.py`

The improved and final version.
This reflects the knowledge and practical experience gained over the course of this short project.
This version introduced:

- Custom functions
- `while` loops
- `break`
- `continue`
- `try` / `except`
- `ValueError`
- Input validation
